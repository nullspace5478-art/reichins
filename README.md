## 📁 ディレクトリ構成

```text
site/
├── index.html                  # メインページ
├── reichins_single.html        # 単一ファイル版（ポータブル版）
├── guide.js                    # 包括的ガイド・法的見解・円周率データ
├── css/
│   └── styles.css              # カスタムスタイル
└── js/
    ├── core/                   # 状態管理・メタデータ解析
    ├── features/               # 各種ギミック・モーダル・UI機能
    │   ├── civil-code-data.js  # 民法条文データ
    │   ├── civil-code-modal.js # 民法モーダル
    │   ├── legal-documents.js  # 法務文書データ
    │   └── ...
    └── processing/             # 画像処理エンジン
```
